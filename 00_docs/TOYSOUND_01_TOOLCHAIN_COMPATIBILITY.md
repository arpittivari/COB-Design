## Key Unresolved Tool Items

1. **WSL2 not installed** — must install Ubuntu 22.04 LTS before any simulation or synthesis.
2. **OpenLane 1.0.x installation** — must be set up in WSL2 following Docker procedure from eChipHub guide.
3. **Ngspice** — must be installed in WSL2; analog PDK SPICE models must be extracted before oscillator simulation.
4. **iverilog SystemVerilog support** — verify that `-g2012` flag supports all SV constructs used in the RTL (specifically `always_ff`, `always_comb`, `unique case`, `$clog2`, struct types). If not, convert RTL to plain Verilog for maximum compatibility.
